## Instalacja GCC w systemach Linux

Aby zainstalować GCC wraz z wymaganymi bibliotekami C w Debianie i Ubuntu, zainstaluj pakiet **build-essential**:
```
sudo apt install build-essential
sudo dnf install gcc
sudo pacman -S gcc
gcc hello.c
```
